14 · Animations & Motion
fadeUp — page section enter: opacity 0→1 + translateY 12px→0 · 0.4s ease · used on every page switch
fadeIn — modal overlay: opacity 0→1 · 0.25s ease
slideUp — modal content: translateY 24px→0 + opacity · 0.3s ease
slideFromBottom — mini player: translateY 100%→0 · 0.3s ease
wave — waveform bars: scaleY 0.3→1→0.3 · 1.2s ease-in-out infinite · staggered animation-delay per bar
Card hover — translateY(-4px) + box-shadow · 250ms · standard on all cards
Button hover — translateY(-1px) + glow shadow · 200ms · btn-primary only
Framer Motion — feed card entrances use motion.div with variants + spring physics · staggerChildren: 0.06
15 · Files Delivered

All design tokens as Tailwind theme extensions — colors, fonts, shadows, animations, gradients, radii. Drop into the monorepo root.

CSS variables + base reset + Tailwind @layer components with all reusable class names + @layer utilities for gradients and scroll rows. Goes in apps/web/app/globals.css.
📖 design-system.html (this file)
Full visual reference — every token, component, and pattern. Share with anyone building on BlushBite so they know exactly what to use.
